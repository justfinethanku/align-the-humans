# ATH-12: setup docs use the OpenRouter key the app reads

**Session:** 2026-10-27, about 04:25 UTC
**Commit:** see the merge commit for the ATH-12 PR on `main`

## What Changed

- `README.md` and `AGENTS.md` list `OPEN_ROUTER_API_KEY` as the AI generation key, document the `OPENROUTER_API_KEY` fallback, and add `RESEND_API_KEY` and `SUPABASE_AUTH_HOOK_SECRET`. `AI_GATEWAY_API_KEY` is described as admin model discovery only.
- `CLAUDE.md` is still the `@AGENTS.md` import from FLEET-98, plus one line that names those same keys.
- `.env.example` and `.cursor/install.sh` already used `OPEN_ROUTER_API_KEY`. Comments now state the fallback.
- `app/lib/ai-config.ts` and `app/admin/system/page.tsx` keep both names. Comments mark `OPEN_ROUTER_API_KEY` as canonical.
- `changelog/2026-07-01-2200-launch-blockers-and-redesign.md` keeps its `ANTHROPIC_API_KEY` sentence and adds a dated note.

## Why

README and the agent instructions told people to set `AI_GATEWAY_API_KEY` for generation. The app reads `OPEN_ROUTER_API_KEY` first. Missing `RESEND_API_KEY` or `SUPABASE_AUTH_HOOK_SECRET` breaks invite and auth email locally.

## How It Was Done

Documented the existing fallback instead of deleting `OPENROUTER_API_KEY`, so an older local name still works. Vercel production on `align-the-humans` sets `OPEN_ROUTER_API_KEY` (names only; values were not recorded).

## Issues Encountered

FLEET-98 had already replaced `CLAUDE.md` with `@AGENTS.md`, so the env list now lives in `AGENTS.md`. `CLAUDE.md` names the same keys in one line so the file the issue cites still lists them.
